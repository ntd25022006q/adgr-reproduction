\section{Goals}
\begin{itemize}[leftmargin=*]
\item Rebuild the full ADGR system from the paper: corpus, knowledge graph,
retrieval, evaluation.
\item Every number traceable to the paper: match where it matches, measure
the cause where it differs, hide nothing.
\item Output: FINAL numbers + 10 figures + this report, ready to present.
Each figure below carries its own reading guide.
\end{itemize}

%====================================================================
\section{Work done, part by part}
\begin{itemize}[leftmargin=*]
\item \textbf{Corpus:} crawled 1,934 medical articles (5 dead URLs, 4
recovered from alternates, disclosed); cleaned HTML keeping structure.
\item \textbf{Chunking:} one H2 section = one chunk $\rightarrow$ 15,837
chunks (91.9\% of paper; min 126, median 799, mean 1,079 chars).
\item \textbf{Graph:} Qwen2.5-14B temp 0 $\rightarrow$ 52,578 entities /
106,279 relations (paper: 49,274 / 106,666); 10.6 entities/chunk average.
\item \textbf{Retrieval:} 300 questions $\times$ 5 pipeline variants (full +
4 ablations, each disabling exactly one module per Sec.~5.8) + 2 LightRAG
baselines with rerank off per Sec.~5.2.
\item \textbf{Scoring:} Hit/MRR/nDCG (dual gold proxies); 4-part RAGAS by
official algorithms; AI judge on 4 dims $\times$ 5 independent runs; per-row
tokens and latency.
\item \textbf{Quality control:} per-question checkpoints (any crash loses
$\le$1 row); self-checks after each stage (bad numbers halt loudly via
validation gates); every bug fixed with remote-verified evidence (43 total).
\end{itemize}

%====================================================================
\section{Main contributions of this reproduction}
(1) Graph at 92--107\% of paper scale \textit{with} all four quality metrics
recomputed from raw extraction (DSER 0.913, SCR 0.884, LCR 0.816).
(2) Found and fixed 2 ablation arms computed against Sec.~5.8. (3) Official
RAGAS algorithms reimplemented. (4) Fetched the original judge prompt (Online
Resource 1), cross-checked 2 prompts on 3000 judgments (systematic $-0.09$
scale shift, rankings kept). (5) Decomposed the faithfulness gap by experiment
(two-step 0.77 vs one-step 0.41 vs paper 0.89). (6) Operating rules distilled
from 43 real failures.

\section{Function of every entity in detail}
\begin{itemize}[leftmargin=*]
\item \textbf{Crawler:} 1,934 URLs $\rightarrow$ title, H2 tree, clean text,
source URL. Handles 404/timeout/429 by backoff retries + alternate sources.
\item \textbf{Cleaner:} drops ads/menus/recommendations/duplicates; keeps
titles, H2, URLs. Encoding audit: 0 mojibake.
\item \textbf{Chunker:} H2-aligned sectioning with recursive split that keeps
parent metadata (matches the authors' chunker at 91.9\%).
\item \textbf{Extractor:} per chunk $\rightarrow$ entities (name, 10+1 type,
description) + relations (source, target, keywords, description) + source
chunk id, temp 0, delimiter format.
\item \textbf{Index:} normalized matrices (768-dim), BM25 over names and
descriptions, two-way graph-to-chunk maps (960\,MB, 8 files).
\item \textbf{Keywords:} 3--6 short $K_l$ + 1-sentence $K_h$, lexical fallback,
memoized (1 call/question).
\item \textbf{Anchors:} BM25 top-10 $\cup$ dense top-10, $\tau_{anchor}$ filter,
overlap bonus, top-15.
\item \textbf{Edges:} one-hop neighborhoods, $\tau_{edge}$ filter, joint score,
quota $m$, cap $N_{max}$.
\item \textbf{Global/direct:} top-$n_g$ relations + top-$n_s$ chunks.
\item \textbf{Merge:} rank by query similarity keeping $\lfloor rn/2\rfloor$,
round-robin interleave, dedup ($\sim$100-chunk pools).
\item \textbf{Reranker:} Qwen3-0.6B, GPU/CPU auto-pick with per-row fallback,
exact-length scores.
\item \textbf{Generator:} vLLM Qwen2.5-14B-AWQ temp 0, 400 tokens max.
\item \textbf{Judges:} Hit/MRR/nDCG, 4 RAGAS parts, 4 dims $\times$ 5 runs
(cost escalation, quota guard), timers.
\item \textbf{Merger:} 8 tables + 10 figures; missing files land in pending.
\end{itemize}

\section{Strengths}
Paper: relevance control at the two most error-propagating stages (removing
anchors drops RAGAS most: 0.88$\rightarrow$0.72); compact contexts ($-67\%$
tokens) cutting total latency; honest ablations; public resources. Ours:
Table-2 lock 13/13; gates blocking corrupt numbers (fired twice, both
correct); dual-proxy absolute agreement; every substitution disclosed with
measured effect; 43 fixes with remote-verified evidence.

%====================================================================
\section{Weaknesses and limits, stated plainly with numbers}
Paper (Sec 6.3): KG-quality dependence; fixed top-K (too much for easy, too
little for hard). Ours: (1) proxies favor dense by definition (measured 0.90,
disclosed, never presented as paper numbers); (2) stricter judge, esp.\ long
answers (short 0.89 vs long 0.53 by quartile); (3) different standalone models
(references only); (4) noisier extraction (LCR 0.82); (5) faithfulness gap
decomposed above.

%====================================================================
\section{Proposed fixes (evidence + cost each)}
(1) \textit{Question-adaptive pipeline:} dense\_only nears full (0.90 vs
0.79) $\rightarrow$ classify easy/hard, skip graph for easy, $\sim$10$\times$
cheaper, expect $\ge$95\%. $\sim$4h + $\sim$\$1. (2) \textit{Rank-fusion:}
rerank drags Hit@1 $0.57\rightarrow0.25$; fusion keeps both. $\sim$3h.
(3) \textit{Sufficiency stopping} (paper's own future work): stop when
supported claims saturate. $\sim$5h. (4) \textit{Length control:} short
answers match paper. $\sim$4h.

\section{Significance and conclusion}
Scientifically: independent confirmation that query-aware relevance control
drives the gains, plus a reusable verification template for any RAG paper.
Practically: 52k-entity Vietnamese medical KG + runnable chain + rules from 43
real failures are permanent assets; each new idea costs marginal compute.
Conclusion: correct mechanisms, rankings, ablation directions; gaps quantified
by cause. No mocking, no cherry-picking, no invented numbers.
